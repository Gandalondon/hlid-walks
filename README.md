# Hlid walks

Walk maps for the Hlid app, one file per walk, one folder per region. The app holds the list of walks and fetches a walk's file the first time it's picked, then keeps it on the phone.

Built by `tools/walkdata/region.py` and written here by `tools/walkdata/inject.py` in Gandalondon/hlid. Don't edit these files by hand.
